## ✨ 社区版包含

- 🔐 **RBAC 权限** + 动态菜单（菜单表驱动，按钮级权限）
- 📊 **仪表盘**：统计卡片 + ECharts 图表 + 欢迎语
- 📋 **表格 / 表单**：增删改查、分页、筛选的完整范式
- 🌗 **暗黑模式** + 主题色自定义
- 🧩 **交付样板页**：电商订单管理、CRM 线索管理（真实 mock 数据，点得进去）
- 🛠 **个人中心 / 帮助中心 / 授权定价页**

## 🚀 快速开始

```bash
# 安装依赖（Node 18+）
npm install --legacy-peer-deps

# 启动开发服务器
npm run dev
```

打开后使用 **任意用户名 + 密码 `123456`** 登录（Mock 数据，免后端）。
