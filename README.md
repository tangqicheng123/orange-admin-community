## 🚀 快速开始

```bash
# 安装依赖（Node 18+）
npm install --legacy-peer-deps

# 启动开发服务器
npm run dev
```

打开后使用 **任意用户名 + 密码 `123456`** 登录（Mock 数据，免后端）。
